## What I'm building

- **[medical-rag-system](https://github.com/KashishhKhann/medical-rag-system)** — End-to-end medical RAG pipeline with FAISS, Neo4j knowledge graphs, and BioClinicalBERT embeddings over clinical notes
- **[Hearthline](https://github.com/KashishhKhann/Hearthline)** — AI inbox triage for property managers: scores and routes every resident message (email, web form, SMS, WhatsApp), drafts replies, and escalates emergencies to on-call staff via Twilio
